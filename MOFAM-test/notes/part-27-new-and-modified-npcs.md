## Row 8 is a genuine hole

> "main file v. 2.91 + optional Street Vendors of Cyrodiil v2.91 - Not in IC;
> install separately"

Two things are wrong with this row, and neither is mudcrab's doing:

1. **v2.91 is not on this machine.** The downloads hold 2.8, 2.9, 2.92 and
   2.93. The version the guide names is not among them.
2. **The Oracle does not have this mod in any version.** Every other Part 27 row
   is there; this one was skipped, so there is nothing to compare against.

Installed at **2.92** — the nearest version where *both* the main file and the
Not-in-IC variant exist, which beats pairing 2.9's main file with 2.8's variant.
It postdates the guide by two months and `diff` flags it.

The two mods therefore show as extras in every future full-list diff. That is
correct: we follow the guide, and the guide asks for them.
